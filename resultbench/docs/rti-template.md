# RTI request template (plan section 6.2)

File online at <https://rtionline.gov.in> for central bodies (CBSE, NTA, NIC
under MeitY) or with the state's RTI portal or Public Information Officer
(state boards, AKTU). Fee: ₹10 for central bodies; state rules vary. One
request per public authority. Keep each question narrow so it can be answered
from existing records.

---

**To:** The Central/State Public Information Officer, *[name of public authority]*

**Subject:** Request for information under Section 6(1) of the Right to Information Act, 2005, about the online publication of *[examination name and year]* results

Sir/Madam,

I am an M.Tech student at *[institution]* studying how examination result
websites can be made reliable for students. I request the following
information from existing records about the publication of results of
*[examination, e.g. Class XII examination 2026]* on *[date]*:

1. The peak number of requests (hits) per second or per minute received by the official result website(s) on the day of publication, and the time at which it occurred.
2. The peak number of concurrent users or sessions recorded, if available.
3. The total number of result look-ups on the day of publication and on the following day.
4. The number of servers or virtual machines, and the hosting arrangement (for example NIC data centre, MeghRaj cloud, a private provider), used to serve the result website on that day.
5. Whether a content delivery network or a waiting-room (queue) system was used.
6. Any post-incident report, review, or note prepared about slowness or unavailability of the result website on that day.
7. The number of results published through alternative channels (SMS, IVRS, DigiLocker, UMANG) on that day, if recorded.

If any item is held by another public authority (for example NIC), kindly
transfer that part under Section 6(3).

I am a citizen of India. I prefer to receive the information by email at
*[email]* or in electronic form. The fee of ₹10 is paid *[online / by IPO
no. …]*.

Yours faithfully,
*[Name]*
*[Address]*
*[Date]*
